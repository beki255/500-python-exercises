# 500 Python Exercises

A comprehensive collection of 500 Python programming exercises for beginners to intermediate learners. Each exercise is contained in its own `.py` file, making it easy to practice one concept at a time.

## 📋 Description

This repository contains 500 individual Python exercise files covering fundamental to intermediate programming concepts. Each file is self-contained with working code examples that demonstrate specific programming concepts, making it perfect for:
- Self-study and practice
- Teaching and training
- Interview preparation
- Code review and learning

## 📂 Exercise Categories

| Range | Category | Count | Topics |
|-------|----------|-------|--------|
| 001-050 | Basic Operations | 50 | Addition, subtraction, multiplication, division, area calculations, temperature conversion, etc. |
| 051-100 | Conditionals | 50 | If/else, leap year, grade calculator, voting eligibility, etc. |
| 101-150 | Loops | 50 | For/while loops, patterns, series, searching, etc. |
| 151-200 | Functions | 50 | Function definitions, lambda, decorators, recursion, etc. |
| 201-250 | Lists | 50 | List operations, comprehensions, sorting, filtering, etc. |
| 251-300 | Strings | 50 | String manipulation, checking, formatting, etc. |
| 301-500 | Advanced Topics | 200 | Dictionaries, sets, files, OOP, exceptions, modules, etc. |

## 🚀 How to Use

### Running an Exercise

```bash
# Navigate to the directory
cd C:\2018\python\CodingPython\

# Run any exercise directly
python ex001_add_two_numbers.py
python ex050_calculate_speed.py
python ex150_missing_number.py
```

### Exercise File Naming Convention

Files follow the pattern: `ex{NNN}_{descriptive_name}.py`

Example: `ex001_add_two_numbers.py`
